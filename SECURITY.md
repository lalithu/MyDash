# Security

Please report vulnerabilities privately to lalithuriti@gmail.com. Include the affected version, reproduction steps using your own test data, and expected impact. Do not post session tokens, passwords, personal schedules, or live exploit details in public issues.

A Supabase publishable key is intentionally public. Service-role keys, database passwords, and user access or refresh tokens must never be committed. Access control must be enforced by database policies and authenticated RPCs.
